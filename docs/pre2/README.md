## 选择版本

本手册对应 `v0.135.0`。源码标签和 Release 已发布：<https://github.com/sqlrush/pgrac/releases/tag/v0.135.0>。四节点安装按[安装手册](install.md)第 2 节从该标签获取源码并编译；Release 附带 ARM64 单机评估镜像的分卷、`SHA256SUMS`、`ARCHIVE-SHA256SUMS` 和 `DELIVERY-README.md`，下载与校验方法见[镜像使用说明](vm-image.md)。不使用其他版本的包名和校验值代替。

安装流程是源码编译及向四节点分发同一产物，不以虚拟机镜像作为前置条件。安装记录应包含实际 tag、commit、构建配置与 SHA-256。

## 开始前

以下要求适用于按[安装手册](install.md)进行的四节点安装部署。ARM64 单机镜像是另一条评估路径，运行要求和操作方法见[镜像使用说明](vm-image.md)。

- 使用四个独立 Linux 节点以及经过准备的共享存储；单机四进程不等于本文的四节点环境。
- 四节点安装部署中设置 `cluster.lms_workers=2`，业务连接池配置为每节点不超过 16 个并发连接；其他值按安装手册的参数表设置。
- 保留数据校验、同步提交、写入保护和隔离守卫，不通过关闭检查绕过启动或 SQL 错误。
- 功能评估从少量连接、短事务开始；共享模式下被拒绝的 SQL 操作见产品说明。
- 启动或停机异常时，保留数据、WAL 和四节点日志，联系技术支持。

旧的 [PRE1 部署手册](../deployment/pre1-quickstart.md) 和 [通用安装手册](../user-guide/install.md) 可用于补充阅读，不能替代本专区的 PRE2 初始化与启停步骤。
