# PRE2 功能评估技术预览

Author: SqlRush <sqlrush@gmail.com>

## 选择版本

本手册对应 `v0.135.0`。**截至 2026-10-10，GitHub 尚无该标签或 Release，标签下载步骤当前不能执行，也没有该版本的已发布二进制或 `SHA256SUMS` 资产。** 下载状态以[公开发布列表](https://github.com/sqlrush/pgrac/releases)为准，不使用其他版本的包名和校验值代替。

安装流程是源码编译及向四节点分发同一产物，不以虚拟机镜像作为前置条件。安装记录应包含实际 tag、commit、构建配置与 SHA-256。

## 已知限制

- 四台 VM 的集群总吞吐约 **100 TPS**，仅为特定环境读数，不是容量承诺。
- **每节点 16 个并发业务连接只做过短时验证**；该范围不是持续运行保证，也不是 `max_connections` 的硬上限。
- 持续负载约 **20 分钟后出现过 SQLSTATE `53R97`（`RECYCLED_AUTHORITY_UNPROVABLE`）**，同轮有节点 VM 被关机；两项现象不作为唯一因果结论。
- **正常停机可能出现 `FATAL` / `PANIC`、进程提前退出而失败**。失败后再次启动未经验证，本文不提供异常恢复步骤；保留现场，另建全新评估库。
- 无论 autovacuum 开关如何，当前 **VACUUM / VACUUM FREEZE 不能冻结或回收旧行版本**，长时间写入会使表持续膨胀。
- **`cluster.lms_workers` 必须保持 `2`**；大于 2 时额外 worker 建连失败，并导致停机失败。

## 开始前

- 使用四个独立 Linux 节点以及经过准备的共享存储；单机四进程不等于本文的四节点环境。
- 保留数据校验、同步提交、写入保护和隔离守卫，不通过关闭检查绕过启动或 SQL 错误。
- 功能评估从少量连接、短事务开始；故障注入、自动接管、长时间运行或性能压测不在本预览范围。
- 停机异常、空间持续增长或 SQL 返回无法判定的错误时，停止评估并保留四节点日志和数据。

旧的 [PRE1 部署手册](../deployment/pre1-quickstart.md) 和 [通用安装手册](../user-guide/install.md) 可用于补充阅读，不能替代本专区的 PRE2 初始化与启停步骤。
