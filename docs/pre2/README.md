# PRE2 功能评估技术预览

Author: SqlRush <sqlrush@gmail.com>

本专区面向在隔离环境中评估 PGRAC 的用户，介绍四节点部署、日常操作和已知使用限制。PRE2 用于功能评估，不提供生产高可用、故障切换或性能承诺。每节点不超过 16 个并发业务连接是本轮评估范围，不是 `max_connections` 的产品硬上限。

## 选择版本

客户源码及拟交付镜像固定到已发布标签 [`v0.133.1-pre2.1`](https://github.com/sqlrush/pgrac/releases/tag/v0.133.1-pre2.1)，对应 `2d857abffc76a5cbfbc1b01c7d99b82ab0375f46`。镜像仍需完成独立新副本验证，不能因标签已发布就认为镜像已经可下载或通过验证。

安装手册还标注了 `c45bdc5d4392751a33659acf8dcaa2b76254e73a` 的实验室操作记录和验证限制。该 commit 与上述标签不同；取得二进制包时，以交付方提供的源码 commit、构建配置和 SHA-256 为准，不混用二进制、数据目录或配置，也不把另一构建的验收结果直接套用过来。

## 开始前

- 使用四个独立 Linux 节点以及经过准备的共享存储；单机四进程不等于本文的四节点环境。
- 保留数据校验、同步提交、写入保护和隔离守卫，不通过关闭检查绕过启动或 SQL 错误。
- 功能评估从少量连接、短事务开始；暂不安排故障注入、自动接管、长时间运行或性能压测。
- 停机异常、空间持续增长或 SQL 返回无法判定的错误时，停止评估并保留四节点日志和数据。

旧的 [PRE1 部署手册](../deployment/pre1-quickstart.md) 和 [通用安装手册](../user-guide/install.md) 可用于补充阅读，不能替代本专区的 PRE2 初始化与启停步骤。
